# KDevTool

iOS 工程的本地开发辅助工具（macOS）：一键切换分支 / worktree、把指定 Pod 切到本地开发、执行 pod 命令、编译并打开工程。

本仓库仅托管发布产物：

- [Releases](https://github.com/wangwanjie/KDevTool/releases)：已签名并公证的安装包（`arm64` / `x86_64`）
- `appcast-arm64.xml`、`appcast-x86_64.xml`：Sparkle 自动更新源
- `release-notes/`：各版本发布说明

最新版下载请到 [Releases](https://github.com/wangwanjie/KDevTool/releases/latest)。系统要求 macOS 14.6 及以上。
